# Wiggle Pop feedback log

## 2026-09-18 — Implemented updates

- **Games navigation:** added the centred `Games` action to the home navigation and retained the theme switch on the right.
- **Games catalogue:** added an age-filtered catalogue with Free Play shown first, followed by Memory and Pop & Play.
- **Free Play:** added the existing **Smash!** experience to the Free Play catalogue.
- **Tile Memory:** added age-scaled animal memory boards, corrected the medium board to show all 12 cards in a 4-by-3 layout, and added a completion celebration overlay.
- **Balloon Pop:** added letter-and-number keyboard popping, five waves (10 to 50 balloons), start and inter-wave celebrations, and a retry state after an unpopped balloon reaches the top and bounces three times. Removed non-keyboardable colour and shape balloons.
- **Find It!:** added five visual animal-finding rounds, age-scaled choice grids, gentle wrong-choice feedback, a completion celebration, and a compact layout that fits the full board inside the browser view.
- **Colour Splash:** added a no-win/no-lose persistent artwork activity for ages 2–3, with random local marks, keyboard/pointer input, and a visible Clear action. Aligned the Clear and Games control text vertically.
- **Back navigation:** replaced text-style back arrows with left chevrons across the game pages.
- **Bible Stories:** added the new home-navigation link and story-collection page. Corrected its scrolling so the page itself scrolls within the app shell, including to the final closing section on smaller screens.
- **Bible Stories background:** removed the decorative gradient circles; keep this page background clean and solid in both light and dark modes.
