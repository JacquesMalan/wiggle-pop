# wiggle-pop

## Release

The current Android release baseline is version **1.0.0** (`versionCode` 1). See [the Play Store release checklist](docs/PLAY_STORE_RELEASE.md) for the required build, child-safety, policy, signing, device-test, and Play Console gates.
Wiggle Pop is a playful, fullscreen keyboard-and-pointer experience for young children—turning taps, mouse movement, letters, numbers, and special keys into colourful particles, fridge-magnet characters, and friendly emoji surprises.
